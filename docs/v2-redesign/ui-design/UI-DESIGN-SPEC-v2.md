## 1. 设计原则与跨产品最佳实践吸收（Rev.3 核心重构依据）

针对用户实测中指出的 4 项关键体验问题（宽屏留白过多、首页模块晦涩难懂、知识库看不到原文、收件箱缺原文阅读），本版全面吸收 4 类标杆产品的成熟交互模式：

- **Obsidian（文档优先，零学习门槛）**：一打开应用直接进入**本地文档知识库**，而不是管理后台仪表盘；左侧真实目录同时看得到整理后的知识页与所有原始文件；正文支持 **「适读宽 / 铺满宽」** 一键切换，支持一键 **50/50 左右分屏对照原文**。
- **Readwise Reader / Cubox（先舒心读原文，再轻量化标重点）**：收件箱点开文章即进入清爽的**完整原文阅读视图**，顶部提供醒目 **「打开原网页 ↗」** 按钮；阅读时点击任意段落即可高亮标为重点（去掉生硬的表单复选框），右侧同步提供 AI 3 句话导读与已标重点汇总。
- **NotebookLM（有据问答 + 按需分屏核验）**：右侧固定简洁的双页签（**「文档信息」** 与 **「AI 问答」**），回答里的每处引用点一下即在中区展开来源原文分屏，平时不打断阅读流。
- **Linear / Notion AI（渐进式披露，消灭治理噪声）**：撤除晦涩的 5 卡片“工作台”与「本周审阅预算」进度条，删去每个二级标题上重复的 `后台增量维护` 标签；仅在出现真实观点矛盾时给出温和提示，并将全部 AI 后台整理记录与可选复习收拢进极简两栏的 **「整理」** 页。

## 2. 视觉系统：A 深色（默认）+ C 浅色双主题切换

确认采用 **A（Cognitive Slate 深色默认）** 与 **C（Paper Daylight 浅色）** 配对切换（已移除原 B 方案）：

| 主题 | 定位 | 核心色阶（Canvas / Surface / Text / Accent） | 切换入口 |
|---|---|---|---|
| **深色 · Cognitive Slate（默认）** | 延续 `DESIGN-01` 的克制工具深色 | `#111316` / `#1a1c1f` / `#e2e2e6` / `#cbbeff`（Ink `#24096a`） | 左导航底栏一键图标 + 设置 → 外观 |
| **浅色 · Paper Daylight** | 温润纸白高对比，日间阅读无反光 | `#f5f3ee` / `#ffffff` / `#1c1b18` / `#4c3fd1`（Ink `#ffffff`） | 左导航底栏一键图标 + 设置 → 外观 |

- **离线字体**：随包本地加载 `Hanken Grotesk` 与 `JetBrains Mono`，中文回落 `Microsoft YaHei UI`，零外链 CDN 依赖。
- **反冗余原则**：零装饰渐变、零 AI 发光球、零 Emoji、零每节重复的机器状态标签；正式交付版不保留原型左下角「预览」浮层，明暗主题与默认宽度收归左底栏与「设置 → 外观」。

## 3. 信息架构与宽屏 / 高 DPI 双端像素契约

### 3.1 左侧 56px 主导航（4 个 5 秒即懂的去黑话入口）
1. **知识库（默认启动首页）**：完整本地 Markdown 文档查看与编辑器。左栏提供 **「全部 / 知识页 / 原文」** 筛选，默认「全部」直接并列展示 **`整理后的知识（wiki/）`** 与 **`原始文件（raw/：随手笔记、收藏原文）`**。
   - 查看**知识页**：支持阅读/源码切换、`对照原文` 50/50 分屏、`铺满宽 / 适读宽` 切换、`让我讲一遍` 与 `Obsidian` 打开。
   - 查看**原始文件**：以只读原件完整展示你写下的随手笔记或收藏原文，顶部直接列出 **「已整理进哪些知识页」** 双向跳转，网页剪藏直接提供 **「打开原网页 ↗」**。
2. **收件箱**：收集的网页文章与长文阅读空间。左栏为 `未读 / 已处理 / 全部` 列表，中区默认进入 **「完整原文」** 阅读器（附 `打开原网页 ↗` 与 `已标重点 (N)` 视图切换），右栏自动展示 **「AI 3 句话导读 + 你标出的重点 + 相关知识页」**。
3. **整理**（仅在有未确认冲突时显示琥珀色角标）：两栏白话布局——左栏为 **「需要你确认的冲突」** 与 **「可选的复习与关联建议」**；右栏为 **「待整理缓冲队列（有快记时出现）」** 与 **「AI 最近帮你整理了什么（每批可一键撤销）」**。
4. **图谱**：交互式知识图谱与键盘等价关联列表，点连线即看形成关联的原文依据。
- 左导航底部固定 **深浅主题切换** 与 **设置**。

### 3.2 宽屏利用率与窄视口 DPI 适配（覆盖 1920×1080 / 1440×900 / 1100×700）
- **1600px–1920px 宽屏**：知识库与收件箱默认均展开平衡的 **三栏工作台**（左 `276px` + 中区流体舞台 + 右 `376px`），彻底告别空旷黑边；文档正文默认适读宽提升至 **`920px`**，并提供 **「铺满宽（100%）」** 一键切换；点击「对照原文」展开 **50/50 双文档分屏**；「整理」页与「冲突左右对比」页最大容器宽度放宽至 **`1680px`**，双栏/三栏充分利用宽屏。
- **1100×700 窄视口（覆盖 1080p @ 125%–150% DPI）**：
  - `< 1240px` 视口下左右栏互斥（展开一侧自动收起另一侧），保证正文净宽始终 **`≥ 560px`**、首屏正文可见高度 **`≥ 420px`**、零横向溢出；
  - 冲突对比页通过容器查询 `@container stage (min-width: 880px)` 响应，收起侧栏后在 `1100px` 窗口依然保持并排对照。

## 4. 核心交互底线与前端实现守卫

1. **随手记浮窗（`Win+Alt+N`）**：四级 `Esc` 优先链（`中文组词期 → [[ 补全框 → 空内容直接关窗 → 非空收起暂存草稿`），绝不静默提交；写盘失败保持可编辑，诚实提示「内容仅暂存内存」并高亮「复制全文」；保存后的笔记立即可在知识库「原文」里查看到。
2. **60 秒不顺延合批缓冲与焦点守卫**：后台倒计时归零自动整理时，若检测到 `INPUT`、`TEXTAREA` 或 `contenteditable`（及正式前端 CodeMirror 实时编辑态）正处于活跃输入/组词中，严禁破坏性重绘焦点；状态栏常驻独立缓冲槽位并提供「查看/撤回」与「立即整理」。
3. **「让我讲一遍」按页隔离遮蔽**：启动后按 `pageId` 隔离遮蔽当前页的核心正文、「我的理解」与原文引文（切换至其他笔记页时自动复位，杜绝串页遮蔽）；3 步复述后支持自评与一键追加进受手动保护的「我的理解」。
4. **冲突对比防呆与隐私边界**：多页冲突对比支持单页微调/跳过；选择「两个都保留」强制校验适用范围非空；设置页统一收口「数据发送范围矩阵」并随 URL 输入实时区分本机回环与非本机远端风险，API Key 仅存 Windows 凭据管理器。
5. **跨视图全局搜索（`Ctrl+K`）**：任意视图同时检索**知识页标题、全部原始文件正文与原文引文**（后端搜索接口须完整覆盖 `wiki/` 标题、`raw/` 全文与原文引文三源，不得退化为仅搜知识页），并常驻「直接问 AI」兜底入口；无边框顶栏搜索框两侧保留显式窗口拖拽热区，最小化（`_`）缩回任务栏、仅关闭（`×`）入托盘。
6. **正式版清理项（Carbon Round 3 交接提醒）**：正式前端实现时移除原型左下角「预览」调试按钮，将明暗主题（A 深色 / C 浅色）与默认文档宽度（适读宽 / 铺满宽）持久化写入应用设置。

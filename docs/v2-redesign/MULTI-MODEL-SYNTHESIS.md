## 2. 16 项关键决策逐条比对与归因表

### T1｜编译执行机制与信任防线
- **最终统一决策**：Agent 仅可输出结构化 **`EditOp`**（`create_page / append_section / replace_section / delete_section / add_link / add_alias / set_frontmatter_key / insert_callout`），由 Rust 侧校验执行，**严禁整页重写**；打包为 `Changeset`（记录来源修订号、模型 ID、写前快照与一键回滚）。按操作类型确定性放行：新建带出处来源页、`add_link`、非人工区 `append_section` 自动落盘；`replace_section`、改写范围/条件、触及人工区、写核心决策页必须审阅；单批触及 >15 页整批刹车进审阅。上层设**每周 15 分钟审阅预算**，超限时按 `EditOp` 类型降级（先停 `replace_section` 提案，`add_link` 照常），不让 LLM 自评。取消每周抽检卡与 7 天回滚自动降级；仅当同类驳回两周内出现 ≥3 次时（v2.1）提议 `SCHEMA.md` 补丁。
- **采纳了谁**：融合双方（`EditOp` 写入协议与 >15 页刹车来自 **Claude**；类型化放行语义与每周审阅预算总阀来自 **GPT-Astra**）。
- **另一边为什么没采纳**：
  - GPT-Astra 原方案的 `Change Set` 未限定写入粒度，整页重写易在 Diff 噪声里悄悄抹掉 Obsidian 插件块、未知 Frontmatter 与人工段落；
  - Claude 原方案的“30% 变更比 / PageRank 阈值”无法度量语义风险（删掉一个“不”字变更比近乎为 0，后果却极重）；抽检卡、自适应降级与 SCHEMA 补丁同期上线属过度设计。
- **待验证假设 / 砍刀线**：H1 —— 2 周实测自动 Changeset 回滚率 ≤ 15% 且连续两周审阅耗时 ≤ 15 分钟预算，否则冻结自动落盘先修编译；人工文本丢失 = 0（工程底线）。

### T2｜证据引用链（两跳 vs 一跳）
- **最终统一决策**：采用**一跳证据**。Wiki 正文脚注直接指向 `raw/` 文件或标题锚点，并附 1–2 句**逐字短引**（无标题快记用“文件链接 + 原句”定位）；Rust 侧写盘前确定性校验短引存在于该来源修订版中，核验失败拒绝落盘。`wiki/sources/` 不再作证据中转，改为作者/版本/方法元数据页与**共同来源归组**中心（转载/多份摘录归回原始出处，追不到上游标 `来源关系未明` 不计独立印证）。
- **采纳了谁**：融合双方（一跳直达主张与共同来源归组来自 **GPT-Astra**；逐字短引定位与来源页降格为元数据中心来自 **Claude Round 2 修正**）。
- **另一边为什么没采纳**：Claude 原两跳方案只要来源摘要漏掉一句限定条件（如“仅统计付费用户”），下游多个概念页都会忠实复制错误导致用户不敢引用；GPT-Astra 原纯 `#标题` 锚点在无标题快记与两万字长文中定位失效，而 Raw 不可变不能插 `^id`。
- **待验证假设 / 砍刀线**：短引定位成功率 ≥ 95%；不达标则在 `state.db` 补 Raw 旁路定位索引（不改 Raw）。

### T3｜快记编译触发时机与快捷窗 `Esc`
- **最终统一决策**：`Ctrl+Enter` 原子落盘 `raw/notes/` 并进入**60 秒（30–180 秒可配）可视缓冲窗口**，**从批次首条快记计时、后续快记合入但不顺延**；状态栏展示倒计时与「立即编译」按钮；队列忙时自动合并未开工条目；状态清晰区分 `已保存 / 待编译(倒计时) / 编译中 / 已编入`；`Ctrl+Shift+Enter` 立即编译，支持单次「仅保存」。`Esc` 严格按顺序：① IME → ② 关补全 → ③ 隐藏并保留已持久化草稿，**绝不静默提交**。
- **采纳了谁**：融合双方（合批思想来自 **Claude**；显式状态与 `Esc` 安全顺序来自 **GPT-Astra**；60s 短可视缓冲来自 **主控 PM 裁决**；「窗口不顺延防饥饿」由 **Claude 合成补强**）。
- **另一边为什么没采纳**：GPT-Astra 原“保存即编”在开会 10 分钟连记 5 条同主题笔记时会触发 5 次编译、产生自冲突提案并花 5 倍 Token；Claude 原“3–10 分钟静默滑动去抖”会让用户刚保存打开 Wiki 误以为失效，且持续输入会导致首条无限期等待；Claude 初稿两处对 `Esc` 行为前后矛盾。
- **待验证假设 / 砍刀线**：`Esc` 组词保护为工程底线；若 2 周内手动点「立即编译」占比 > 50%，缩短默认缓冲时长。

### T4｜主工作台信息架构
- **最终统一决策**：**主导航 4 项**（工作台 / 知识库 / 收件箱 / 图谱），设置退到底部齿轮，回顾不单列导航。**右栏 3 页签**（上下文[反链·大纲·属性·局部图] / 对话 / 活动），打开 Wiki 页默认展开「上下文」，在工作台首页默认收起并记住用户状态。**审阅以中区标签页打开**（入口在工作台阻塞卡角标与受影响页内），支持宽屏并排看多页 Diff。对话默认仅带**当前页**，1 跳邻居以可点击 chip 按需加入。
- **采纳了谁**：融合双方（极简 4 导航、审阅从受影响位置进入与默认不自动扩带 1 跳邻居来自 **GPT-Astra**；Wiki 页默认展开上下文与中区宽幅多页审阅来自 **Claude Round 2**）。
- **另一边为什么没采纳**：Claude 原 7–8 个平级入口重犯 v1.0 导航分散错误，且默认带 1 跳邻居可能悄悄扩大问题边界与隐私外发范围；GPT-Astra 原右栏一律默认收起会破坏编辑 Wiki 时高频看反链/大纲的心流，且 320px 侧栏塞不下多页 Diff 对照。
- **待验证假设 / 砍刀线**：从发现“某条判断未更新”定位到对应阻塞项 ≤ 2 次点击。

### T5｜知识采集、Triage 与防积压
- **最终统一决策**：严格**二元分流**（快记为“我的观察”直入编译缓冲；外部文本/链接/文档为“待判断材料”入收件箱）。Triage 设 4 动作：**编入 Wiki / 仅编选段 / 稍后 / 仅存档**（`Enter` 默认「仅存档」，保持 Wiki 入口窄于 Raw）。**未触碰项**（从未打开、无进度）满 14 天静默转为「仅存档」（不动 Raw，每周汇总支持一键恢复）；**进行中项**（已打开阅读、有批注或选段）**永不自动归档**并保留阅读位置与已编范围。首页至多推 1 项，角标只计本周待决。
- **采纳了谁**：融合双方（二元分流、仅编选段与渐进阅读进度来自 **GPT-Astra**；默认窄入口「仅存档」与防积压自动归档来自 **Claude**；「未触碰 vs 进行中」分层保护来自 **主控 PM 裁决**）。
- **另一边为什么没采纳**：完全不归档会在忙碌周后堆出几十条未读制造负罪感导致弃用收件箱；一刀切 14 天归档会误判跨周研读的长文手册；Claude 原「轻编（仅来源页）」档与「仅存档」语义重叠，徒增决策负担。
- **待验证假设 / 砍刀线**：H3 —— 自动归档后 7 天内手动恢复率 ≤ 10%，超标则把阈值延长至 30 天。

### T6｜未决观点分歧的页内警示
- **最终统一决策**：**默认写入 Frontmatter 可读列表 `wikra_pending_conflicts`**（含“断言 + 挑战证据 + 审阅 ID”），不污染正文，Obsidian 属性面板可见且 MCP `read_page` 原样返回警告字段，裁决时结构化删键。**受控例外**：仅在核心决策页（`decisions/`、`type: decision` 或 `wikra-core`）且新证据直接挑战现行结论、不提示会误导实施时，允许在受影响段落旁插入简短受控 Callout；裁决时清理（若曾被人工改动则转 Diff）。仅对 B3 判定的“真冲突”打标；Human 只读区不写。
- **采纳了谁**：融合双方（Frontmatter 主路径来自 **Claude Round 2**；“直接挑战且会误导实施”触发门槛来自 **GPT-Astra Round 2**；限定核心决策页来自 **主控 PM 裁决**）。
- **另一边为什么没采纳**：Claude 初稿全页插正文 Callout 会污染 Obsidian 正文并易在外部编辑后残留残片；GPT-Astra 初稿完全不写页内提示会让 Obsidian 或外部 Agent 照着过期结论实施；GPT-Astra Round 2 在所有授权页写 Callout 范围仍过宽。
- **待验证假设 / 砍刀线**：Callout 清理残留 = 0 且 Frontmatter 写回保留未知键序（工程底线）。

### T7｜交互式知识图谱（v2.1）
- **最终统一决策**：**默认 1 跳局部图**（区分证据引用 / 显式链接 / 反链，点边预览原段，旁配等价键盘关系列表）。**全局图**按类型与标签过滤，**不按目录聚合**；索引与日志页按 `SCHEMA.md` 声明的**页面角色**折叠降噪（不按文件名硬排除）；超 2,000 节点提示转局部视图。Hub / 孤页 / Structural Gaps 必须有共同实体或共同问题证据，允许标“无关”。Louvain 社区发现延至 v2.2 视实测决定。
- **采纳了谁**：融合双方（局部 1 跳优先、边类型、原段预览与键盘列表来自 **GPT-Astra**；排除索引/日志降噪思路与拒绝目录聚合来自 **Claude**；按页面角色折叠来自 **GPT-Astra 修正**）。
- **另一边为什么没采纳**：Claude 原首版引入 Louvain 与共引 Gaps 易因共享泛泛参考文件制造大量假空白洞察；GPT-Astra 原目录聚合在按时间或来源分类的 Vault 中只能画出归档树而非知识结构；按文件名排除会误伤名为 `index.md` 的实质文档。
- **待验证假设 / 砍刀线**：H4 —— 2 周内借图谱找到 ≥ 2 条可解释、可行动的新关系，不达标则冻结图谱不立项 Louvain。

### T8｜对话式回顾与学习（v2.1）
- **最终统一决策**：统一为一个自然流程 **「让我讲一遍」**：收起答案复述 → 对照原文拷问证据与边界反例 → 换场景变式迁移 → 本人自评「能用 / 需再看 / 暂不关心」。选「需再看」按 3 / 7 / 21 天（或自定日期）提醒，首页**仅在有到期项时露出 1 张卡**（无打卡、无理解度打分）。新洞察经本人确认写入该页 `## 我的理解`（受人工段落保护）；盲区作为事件发往选定记忆后端。FSRS 留至 v2.2 对标星页条件试点。
- **采纳了谁**：融合双方（单一流程、本人自评与延后 FSRS 来自 **GPT-Astra**；边界拷问步骤、固定间隔提醒、首页条件露出与洞察回写来自 **Claude**）。
- **另一边为什么没采纳**：Claude 原 4 级理解度状态机等于让 LLM 充当判官，混淆了“熟悉手头案例”与“陌生项目迁移”，还制造评判压力；GPT-Astra 原首页完全不露出容易导致功能被遗忘。
- **待验证假设 / 砍刀线**：H5 —— 2 周内自愿发起 ≥ 3 次且至少 1 次写回 `## 我的理解`，否则撤出首页卡降为页面菜单动作。

### T9｜多记忆体系分工与双跳隐私
- **最终统一决策**：Wiki 存可查证结论/证据/决策依据，记忆体系存个人情境/偏好/取舍理由/反思（同一项目裁决拆分：依据入 Wiki，个人理由经确认入记忆）。模型接入全面支持**任意 OpenAI 兼容模型与自定义网关**，允许个人快记全文发给编译模型。记忆后端采用可插拔 `MemoryProvider` 抽象，**优先打透本地 OpenViking**，后续扩展 Hindsight 等其他记忆体系；默认**单写多读**，`Reflect` 不自动覆盖 Mental Model。**默认关闭 Wiki 全库镜像与快记全文外发至记忆后端**（记忆后端仅收情境事件；OpenViking `resources` 保留按目录/文档显式授权投影与 L0/L1/L2 分层加载）。所有端点（记忆、远端模型、MCP）声明真实接收方性质（本人私有 / 共享实例 / 第三方云商），不盲信 loopback，可选辅助正则脱敏。Mental Model vs Wiki 对账放 Phase 3 由用户主动发起。
- **采纳了谁**：融合双方（默认关闭镜像与全文、事件化外发来自 **Claude**；裁决拆分、单写多读、逐文档投影与主动对账来自 **GPT-Astra**；远端模型同步纳管来自 **主控 PM 裁决**；全端点不盲信 loopback 的接收方声明由 **Claude 合成补强**）。
- **另一边为什么没采纳**：GPT-Astra 原默认投影会带来个人笔记误入公司共享 OV 网关的合规风险；Claude 原“离开我是否成立”单一分界线切不开混含证据与偏好的项目裁决，且“非 loopback 才警告”漏掉了本机代理转发路径。
- **待验证假设 / 砍刀线**：未授权外发 = 0（工程底线）；H6 记忆盲评无增益则保持默认不注入编译。

### T10｜本地 MCP Server
- **最终统一决策**：**v2.0 即交付只读 `stdio` MCP**（显式绑定单个 Vault），提供 3 个工具：`search`、`read_page`（含 `wikra_pending_conflicts` 警告与反链摘要）、`get_evidence`（将脚注解析为原段、短引与来源修订号）。**MCP 客户端同样按外发管理**：默认仅暴露 Wiki 区与脚注短引，Raw 全文需按目录授权。写入提案放 v2.2 且一律进审阅；HTTP 传输等出现明确需求再立项。
- **采纳了谁**：融合双方（提前至 v2.0 来自 **Claude**；仅做 `stdio` 与强调取证据来自 **GPT-Astra**；`get_evidence` 替换 `list_backlinks` 及外发范围限定由 **Claude 合成补强**）。
- **另一边为什么没采纳**：GPT-Astra 原延至 v2.2 会让整个桌面端开发周期拿不到最核心的外部 Agent 复用信号；Claude 原同期做 Streamable HTTP 增加了端口与鉴权维护成本，且 `list_backlinks` 对“保留限定条件 + 可打开出处”的验证价值弱于 `get_evidence`。
- **待验证假设 / 砍刀线**：H2 —— 3 个真实 Codex / Claude Code 任务中至少 2 个找对结论、保留限定条件并给出可打开出处。

### T11｜分阶段路线图切分
- **最终统一决策**：采用 **v2.0（3–4 周）→ v2.1（3 周）→ v2.2（3 周）三段垂直切片**，每段配“1 周旧基线 + 2 周对照实测”与量化砍刀线。v2.0 内分 **W1–2 主干链路**（接库 + 快记 → EditOp 编译 → 回滚/段落保护 → 只读 MCP）与 **W3–4 外围**（Triage 选段、多页冲突审阅、Ops 卡、Query）；若 W3 末进度滞后，按「Query-to-Wiki → 长文分次选段 → Ops 卡降为列表」顺序裁减，主干不砍。
- **采纳了谁**：融合双方（垂直切片与基线对照实测来自 **GPT-Astra**；量化砍刀线来自 **Claude**；三段边界来自 **主控 PM 裁决**；v2.0 版本内砍刀顺序由 **Claude 合成补强**）。
- **另一边为什么没采纳**：Claude 原 M0–M4 水平门禁前 3 周只有编辑器无编译闭环，过晚暴露引用可信度问题；GPT-Astra 原 v2.0 塞入图谱、复述、OV 协同且无砍刀线，存在瀑布膨胀风险。
- **待验证假设 / 砍刀线**：见 PRD §8.2 各阶段量化砍刀线。

### T12｜已有 Vault 兼容与人工文本保护
- **最终统一决策**：采用**三区一控制面**（Raw / Wiki / Human 只读区 / `.wikra/`），本产品完全独立通用、不绑定任何特定外部库。支持**新建标准 Vault 开箱即用**，也支持**无痛接入任意已有 Obsidian Vault**（不搬家，同名 `SCHEMA.md` / `index.md` / `log.md` 逐项预览确认绑定不覆写）；目录映射统一存于应用私有 **`.wikra/config.json`**，绝不侵入修改用户原有 `SCHEMA.md`。`state.db` 按段记录 Agent 写后快照，实现**段落级人工文本保护**（仅人改重叠区转 Diff，不重叠段落照常更新；Human 区始终只读）。全局热键沿用 `Win+Alt+N`，剪贴板热键默认不绑定由用户选配，复用现有 `CaptureEditor.vue`、`storage.rs`、`hotkeys.rs`。
- **采纳了谁**：融合双方（三区一控制面与人改检测思想来自 **Claude**；不搬家预览绑定、段落级粒度、热键习惯与资产复用来自 **GPT-Astra**）。
- **另一边为什么没采纳**：Claude 原“整页降级为仅追加”会导致改一个标题就使整页日后堆积多段互斥结论；GPT-Astra 初稿缺少显式人工文本保护，存在 Obsidian 改段被下次 `replace_section` 覆盖的风险；改默认热键为 `Ctrl+Alt+N` 会打破用户现有习惯。
- **待验证假设 / 砍刀线**：保护区被覆写 = 0、往返保真零格式漂移（工程底线）。

### B1｜外部并发写与同步盘冲突副本（盲区补齐，v2.0）
- **最终统一决策**：`EditOp` 携带基线版本，写前比对 mtime 与内容哈希（不重叠则 rebase，重叠则转 Diff）；写盘一律临时文件原子替换；同步盘冲突副本（`(conflict)`、`-冲突`、OneDrive 机器名后缀、`.sync-conflict-`）按规则移入隔离区，不参与编译。
- **采纳了谁**：采纳 **Claude Round 2 盲区发现**（与 GPT-Astra 写前版本核对一致）。
- **另一边为什么没采纳**：首轮双方均遗漏，若不补齐会导致并发写覆盖或把同步冲突副本误当新材料编译。
- **待验证假设 / 砍刀线**：工程底线。

### B2｜换模型导致编译行为回归（盲区补齐，v2.0 打底 / v2.1 落地）
- **最终统一决策**：v2.0 在每个 `Changeset` 记录模型 ID；v2.1 建立 10 份**纯合成** Raw 金样本，检测到编译模型 ID 变更时自动暂停自动落盘（暂转纯审阅）并回放金样本比对 `EditOp` 分布与触及页数，通过或经用户确认后恢复自动落盘。
- **采纳了谁**：融合（金样本回放来自 **Claude Round 2**；将“阻止切换”修正为“暂停自动落盘”由 **Claude 合成修正**）。
- **另一边为什么没采纳**：用户在外部网关或配置切换器中修改底层模型时，FMD 无法技术拦截切换动作，只能收紧自身的自动写入权限。
- **待验证假设 / 砍刀线**：回放中 `replace_section` 占比或平均触及页数偏离基线 > 50% 时维持纯审阅模式。

### B3｜版本/时间演进 vs 真冲突（盲区补齐，v2.0）
- **最终统一决策**：生成冲突前先比对版本、适用对象与生效时间；可按范围并存的自动标明适用条件（如“v1 支持 / v2 取消”），仅当范围重叠且结论不相容时才请人裁决（提供「并存标范围 / 新替旧保留历史 / 保留旧」三选一）。
- **采纳了谁**：采纳 **GPT-Astra Round 2 盲区发现**。
- **另一边为什么没采纳**：首轮遗漏导致只给二选一时，选对新版也会破坏仍具参考价值的历史事实。
- **待验证假设 / 砍刀线**：进入审阅的冲突项中被用户改判为“其实可按范围并存”的比例 ≤ 20%。

### B4｜远端编译与预分诊模型的隐私外发（盲区补齐，v2.0）
- **最终统一决策**：远端预分诊、编译模型与 MCP 客户端均纳入 T9 接收方声明体系；**发送粒度严格等于授权粒度**（只授权选段就只发选段）；首次为 Vault 启用远端编译须显式确认接收方，未授权时本地保存、阅读与手工编选完整可用。
- **采纳了谁**：融合（问题由 **GPT-Astra Round 2** 发现，**主控 PM** 扩至全模型出口，**Claude 合成**补齐 MCP 一跳）。
- **另一边为什么没采纳**：仅约束记忆后端会导致关了 OV 镜像、长文却照样被送去远端模型做三行摘要，违背用户隐私预期。
- **待验证假设 / 砍刀线**：工程底线。

## 3. 用户最终拍板结论（2026-11-26 已更新）

1. **产品完整度**：**做完整的产品** —— 全部五大支柱（快速笔记与 Obsidian 级编辑、LLM Wiki 平台含 Ops 看板与知识图谱、文本/链接知识采集与 Triage、LLM Wiki Agent 编译/巡检/问答/回顾学习、可插拔记忆体系协同）均为正式交付目标，按 Phase 1 → Phase 2 → Phase 3 三个连续完整阶段稳步落地，Phase 1 不裁剪 Triage 选段、多页冲突审阅、Ops 卡与 Query。

# DESIGN-01 UI 设计基准

2026-11-18 确认采用 Local Knowledge Workspace UI。Flash Marking Down 的主工作台、快捷笔记窗和后续功能界面都沿用这套设计。

## 画板与实施范围

以主工作区和全局快捷唤出记录浮窗为视觉基准。项目参考稿覆盖记录详情、工作区设置、Windows 键位和失败状态。

| 画板 | 用途 |
|---|---|
| 主工作区：时间线回查与随手记 | 主工作台布局、最近记录与搜索 |
| 全局快捷唤出记录浮窗 (Quick Capture HUD) | 独立快捷笔记窗 |
| Flash Marking Down - 主工作台 (时间线、详情与工作区设置) | 记录详情和工作区设置 |
| Flash Marking Down - 快捷笔记窗与状态规范 (Quick Note HUD) | Windows 键位、草稿和保存失败 |
| 个人 Wiki 百科与知识关联面板 | Wiki 浏览与关联区域 |
| 已确认待办事项面板 | 已确认待办界面 |
| 收藏文章：资料区与深度精读 | 收藏与文章学习参考稿 |

画板中的数据和状态仅用于评审样式和信息层次。功能行为与字段以规格和契约为准。[开发规格](../../SPECIFICATION.md) · [交付阶段](implementation-plan.md#2-三个重构交付阶段) · [数据与接口约定](data-contracts.md)

## 界面复用要求

- **布局与组件。** 主工作台沿用导航、工具栏、列表与详情层级。快捷笔记窗以正文编辑器为主体，保留必要的状态和保存操作。后续页面复用相近画板的布局、间距、字号层级、按钮、输入、列表与状态组件。
- **Windows 窗口。** 工作台和快捷窗都隐藏系统标题栏，在界面顶部留出拖动区域。工作台窗口操作放在工具栏，快捷窗在底部提供关闭。首次设置弹窗可关闭工作台。
- **颜色与字体。** 沿用 Stitch 的深色 Cognitive Slate 设计主题。背景用 `#111316`，表面用 `#1a1c1f` 和 `#1e2023`，正文用 `#e2e2e6`，次级文字用 `#cac4d5`，分隔线与描边用 `#484553`，焦点与强调用 `#cbbeff`，成功用 `#6ddc9e`，错误用 `#ffb4ab`。界面字体沿用 Hanken Grotesk，代码和等宽信息用 JetBrains Mono，中文使用 Windows 系统中文字体。字体和图标应能离线显示。
- **复用入口。** 前端复用 [ui.css](../../src/ui.css) 的主题变量、控件和状态样式，以及 [UiIcon.vue](../../src/UiIcon.vue) 的线框图标。西文字体及许可证随应用放在 [public/fonts](../../public/fonts/)。
- **中文与键盘。** 界面默认简体中文，快捷键提示与实际 Windows 绑定一致。键盘焦点始终可见，状态以文字配合颜色表达。快捷窗唤出后聚焦正文，Enter 换行，组词期间由中文输入法处理按键。草稿、保存、关闭和焦点交还遵循功能规格。[工作区与配置](../../SPECIFICATION.md#fr-01-工作区务实文件访问与统一配置) · [快捷窗与每日文件](../../SPECIFICATION.md#fr-02-全局快捷窗与按天每日文件落盘)
- **反馈与验收。** 按实际处理阶段显示空态、处理中、成功及失败等适用状态，为失败保留可执行的下一步。交付时对照画板核对布局、字体、颜色及控件，再用 Windows 桌面构建验证相关流程，覆盖键盘焦点、中文输入法及 125% 和 150% 缩放。首次使用流程检查入口、输入、结果和下一步。[验收规格](acceptance.md)

## 2026-11-24 v1.0 一屏三栏布局与辅助抽屉契约

在完整保留上述 `DESIGN-01` 深色 Cognitive Slate 配色、字体层级、无系统标题栏窗口样式与控件体系的前提下，v1.0 对信息架构做如下收敛（取代旧版左侧 7 模块平铺导航）：

- **主窗口收拢为三栏一屏 + 顶部极简栏**：
  - **顶部栏**：全局搜索框（`Ctrl+K`）+ 快捷日期筛选 + `+ 随手记` + 右上角轻量入口 `⚡ 冲突/变更 (N)` 与 `⚙ 设置`。
  - **左栏**使用「记录 / Wiki / 待办」三个紧凑页签，230px 窄栏内横向排布。Wiki 有标题与路径筛选、内联新建、刷新及目录分组，卡片以文字标识已映射、待审和冲突。
  - **中栏**支持 Markdown 预览、编辑和源码，预览可显示工作区本地相对路径图片。随手记下方显示整理和同步状态。Wiki 页的操作栏可管理映射，下方的关联变更可打开对应 Diff。新建页直接进入编辑，已有页面默认预览。编辑区复用快捷窗编辑器，`Ctrl+Enter` 或 `Ctrl+S` 保存，组词期间保留输入法键位，保存失败时保留草稿与恢复操作。
  - **右栏（常驻记忆对话，可折叠）**：多轮对话消息流（Markdown 渲染、点击引用定位原文、关联冲突卡片、自由复制 + 「复制含引用」按钮）与历史对话切换。
- **轻量右侧辅助抽屉**：点击 `⚡ 冲突/变更 (N)` 或中栏/对话中的冲突入口滑出，包含「观点冲突（Git Merge Conflict 风格双边 Diff，一键选 `Keep Current / Accept Incoming / Keep Both`）」与「Wiki 变更（纯文档行级 Diff 审阅与目标映射管理）」两个子页签。
  Wiki 目标与变更卡上的「工作台查看」可收起抽屉并在中栏阅读对应页面。
- **快捷窗容错**：保留隐藏复用与原位 Markdown 预览，取消失败锁只读与关窗/退出死锁，异常时允许复制或忽略草稿强制关闭。

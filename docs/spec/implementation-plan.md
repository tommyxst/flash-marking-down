# 实施计划与阶段规划 v1.0

更新于 2026-11-24。本计划按 **R1 / R2 / R3** 三个迭代推进，每个阶段都应能独立编译运行。

---

## 1. 重构决策基线

| 维度 | 2026-11-24 已确认决策 |
|---|---|
| 产品节奏 | **先用起来**：打通「快捷键 Markdown 快记 → 每日文件落盘 → 后台即时自动整合 + OpenViking 双路整合 → 一屏主工作台与对话召回」唯一主闭环，经真实使用后再扩展。 |
| 笔记落盘 | **按天归入每日文件**（`<capture_dir>/<YYYY-MM-DD>.md` 块追加），兼顾 Obsidian 阅读习惯并兼容历史一记一文件。 |
| 后台整合 | **保存后立即静默触发**（支持在设置中一键关闭自动触发），非阻塞、离线自动排队。 |
| 主屏形态 | **三栏一屏联动**（左栏记录/待办、中栏原文+内联整理、右栏常驻多轮对话），Wiki 变更与冲突降为右上角轻量辅助抽屉。 |
| 分歧处理 | **Git Merge Conflict 心智模型**：列出双边 Diff，一键选择 `Keep Current / Accept Incoming / Keep Both`，彻底移除重型审计表、全局熔断与 `Ctrl+C` 劫持。 |
| 工程水位 | **主打务实**：去掉常驻目录锁、重解析点/拷贝封杀、4 阶段 2PC、单值 SQLite 库与任务审批流；显式复用 `reqwest` 替换手写 WinHTTP FFI。 |
| 记忆服务 | **接口解耦 + 打透 OpenViking**：保留 `MemoryProvider` trait，一期采用 OV 双路配合（每日原文写 `resources` + 笔记要点提交 Session 抽 `memories`）。 |

## 2. 三个重构交付阶段

| 阶段 | 看板任务卡 | 交付内容与入口 | 前置 | 对应验收 | 完成标准 |
|---|---|---|---|---|---|
| **R1 务实底座减负与设置打通** | `2026-11-24-r1-pragmatic-foundation` | 1. 松绑 `workspace.rs`（去常驻父目录锁、放开云盘/Junction/硬链接/拷贝迁移）；<br>2. 应用配置合并为 `settings.json`；<br>3. 快捷窗取消失败只读锁死与关窗死锁，落盘改为每日 `.md` 块追加 + 常规原子写；<br>4. 显式启用 `reqwest` 替换手写 WinHTTP FFI，修凭据 UTF-16 长度上限，设置弹窗支持模型/OV 一次保存 + 测试连接；<br>5. SQLite 演进至 Schema v5，待办复选框支持直接轻快勾选（含手工任务）。 | 架构文档确认 | AT-01 ~ AT-04、AT-11 | 现有及新增 Rust 测试全绿，`npm run build` 与桌面构建通过；可用每日文件流顺畅记录并直勾待办，无锁目录/云盘误伤。 |
| **R2 一屏主工作台、后台整合与 Git 冲突** | `2026-11-24-r2-single-screen-and-conflicts` | 1. 重构前端为「三栏一屏 + 顶部极简栏 + 右侧辅助抽屉」布局，遵循 DESIGN-01 深色主题；<br>2. 落地单队列后台自动整合 Worker（保存后即时静默触发摘要/决定/待办/冲突检测/Wiki 建议）；<br>3. 落地 Git Merge Conflict 风格冲突抽屉（`Keep Current / Accept Incoming / Keep Both`）与清爽 Wiki 变更抽屉（支持解除映射）；<br>4. 上线右侧多轮对话面板（本地 FTS5 召回 + 对话历史持久化 + Markdown 渲染 + 引文跳转），取消 `Ctrl+C` 劫持，修复本地相对路径图片预览。 | R1 | AT-05 ~ AT-08、AT-12 | 主屏一屏完成“记录查看 → 内联整理 → 勾待办 → 抽屉解冲突 → 本地对话召回”，无需跨 7 个模块跳转。 |
| **R3 OpenViking 深度整合与双源对话召回** | `2026-11-24-r3-openviking-integration` | 1. 落地 `MemoryProvider` trait 与 `OpenVikingProvider`（对接本机 v0.5.2 `/health`、`/content/write`、`/sessions/.../commit`、`/search/search`、`/content/read`）；<br>2. 打通双路同步：每日文件写入 `viking://resources/flash-marking-down/<workspace>/daily/` + 新笔记要点提交 Session 抽取长期 `memories`，含失败重试与一键补推；<br>3. 升级右侧对话为「本地 + OpenViking 双源混合召回 + 流式输出 + 来源标签跳转 + 离线降级本地」；<br>4. 完成 Windows 实机端到端走查，正式进入个人日常试用。 | R2 | AT-09、AT-10、AT-11、AT-12、E2E-Core | 使用本机真实 OpenViking 与模型端点走通完整 E2E-Core；进入 1–2 周个人真实日常试用。 |

---

- **阶段实施约束**：遵循 [开发规格的安全边界与性能基线](../../SPECIFICATION.md#5-安全边界与性能基线)。R1 以简化文件访问和写入流程为目标。R2/R3 使用单队列后台任务和独立失败反馈，保留剪贴板的正常操作。
